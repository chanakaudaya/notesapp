# Rich Text Editor - Usage Guide

## Quick Start

### Opening the Rich Editor
1. Launch the Notes App
2. Select an existing note or create a new one
3. The rich text editor appears in the main editing area
4. Start typing to add content

### Basic Formatting

#### Making Text Bold
```
Method 1: Click the B button in toolbar
Method 2: Select text and press Ctrl+B
Result: Text appears in bold
```

#### Making Text Italic
```
Method 1: Click the I button in toolbar
Method 2: Select text and press Ctrl+I
Result: Text appears slanted
```

#### Adding Strikethrough
```
Method 1: Click the strikethrough button in toolbar
Result: Line drawn through text
Use for: Completed tasks, removed content
```

#### Adding Code
```
Method 1: Click the code button in toolbar
Method 2: Select text and press Ctrl+`
Result: Text appears in monospace font with background
Use for: Programming snippets, technical terms
```

## Working with Headings

### Creating a Heading
```
1. Click in a paragraph you want as heading
2. Click "H2" or "H3" button in toolbar
3. Entire paragraph becomes a heading

Alternative: Use keyboard shortcuts
- Ctrl+Alt+2 for Heading 2
- Ctrl+Alt+3 for Heading 3
```

### Converting Back to Paragraph
```
1. Click in a heading
2. Click the same heading button again to toggle off
3. Text returns to normal paragraph
```

## Working with Lists

### Creating a Bullet List
```
1. Click in a paragraph
2. Click the bullet list button
3. Paragraph becomes a list item
4. Press Enter to add more items
5. Press Backspace twice to exit list

Alternative: Ctrl+Shift+8
```

### Creating a Numbered List
```
1. Click in a paragraph
2. Click the ordered list button
3. Paragraph becomes numbered item
4. Press Enter to add more items
5. Numbers auto-increment

Alternative: Ctrl+Shift+7
```

### Nesting List Items
```
1. In a list item, press Tab to indent
2. Item becomes nested under previous item
3. Press Shift+Tab to un-indent
4. Level continues incrementing as needed
```

### Converting Between List Types
```
1. While in a bullet list, click ordered list button
2. Bullets automatically change to numbers
3. Same formatting preserved (bold, italic, etc.)
```

## Text Alignment

### Aligning Text
```
Left Align:
- Click the align-left button
- Or: Default behavior

Center Align:
- Select paragraph or heading
- Click the center-align button
- Text centers in the editor

Right Align:
- Select paragraph or heading
- Click the right-align button
- Text aligns to right
```

### Alignment with Lists
- Alignment applies to individual list items
- Each item can have different alignment
- Works with both bullet and numbered lists

## Working with Tables

### Inserting a Table
```
1. Click the table icon in toolbar
2. A 3×3 table is inserted
3. Click in cells to add content
4. Tab key moves to next cell
5. Shift+Tab moves to previous cell
```

### Adding Rows to a Table
```
When table is selected, table toolbar appears:

Add Row Before:
- Click "↑ Row"
- New row appears above current row
- Useful for inserting headers

Add Row After:
- Click "↓ Row"
- New row appears below current row
- Useful for adding data
```

### Adding Columns to a Table
```
When table is selected:

Add Column Before:
- Click "← Col"
- New column appears left of current column

Add Column After:
- Click "Col →"
- New column appears right of current column
```

### Resizing Table Columns
```
1. Position mouse over column border in table header
2. Cursor changes to resize cursor (↔)
3. Click and drag to adjust width
4. Width adjustment is temporary in editor
5. Save note to persist changes
```

### Deleting a Table
```
1. Click anywhere in the table
2. Table toolbar appears
3. Click the trash icon
4. Entire table is deleted
5. Undo available with Ctrl+Z
```

### Example Table Usage
```
Meeting Notes Table:
| Topic | Discussion | Owner |
|-------|-----------|-------|
| Budget | Quarterly review | Sarah |
| Timeline | Q4 milestones | Mike |
| Status | 85% complete | Team |
```

## Working with Links

### Adding a Link
```
1. Click the link button (🔗) in toolbar
2. A dialog box appears asking for URL
3. Enter the URL: https://example.com
4. Text in selection becomes a link
5. Link appears in blue with underline

Note: You must select text first or click to create placeholder
```

### Opening a Link
```
1. Click on a link in view mode
2. Link opens in default browser
3. Hold Ctrl while clicking in edit mode to open
```

### Editing a Link
```
1. Select the link text
2. Click link button again
3. Update URL in dialog
4. Press Enter to save
```

### Removing a Link
```
1. Click in the link
2. Click link button (🔗)
3. Enter empty URL or cancel
4. Link formatting removed
```

## Copy, Cut, and Paste

### Copying Formatted Text
```
1. Select text (can include formatting)
2. Press Ctrl+C
3. Paste in same note or elsewhere: Ctrl+V
4. All formatting preserved
```

### Cutting Text
```
1. Select text including formatting
2. Press Ctrl+X
3. Text removed and copied
4. Paste with Ctrl+V elsewhere
```

### Pasting Content
```
From Other Apps:
1. Copy formatted text from Word, Google Docs, etc.
2. Click in editor
3. Press Ctrl+V
4. Formatting automatically adapted to editor

From Other Notes:
1. Copy from another note using Ctrl+C
2. Paste in this note: Ctrl+V
3. Format and structure preserved
```

### Paste as Plain Text
```
1. Copy any formatted content
2. Press Ctrl+Shift+V instead of Ctrl+V
3. Text pasted without formatting
4. All styles removed
```

## Horizontal Rules and Dividers

### Adding a Horizontal Line
```
1. Click in paragraph where you want divider
2. Click the minus (−) button in toolbar
3. Horizontal line inserted
4. Creates visual section break
5. Useful for: Section separation, topic changes
```

## Advanced Formatting

### Code Blocks
```
1. Press Ctrl+Alt+C to create code block
2. Type or paste code
3. Formatting preserved (indentation, etc.)
4. Syntax highlighting applied if language detected
5. Click outside to end code block

Example:
function hello() {
  console.log("Hello, World!");
}
```

### Blockquotes
```
1. Click in a paragraph
2. Use quote shortcut (if available)
3. Or manually format as blockquote
4. Text indented and styled differently
5. Great for: Quotes, emphasis

Style:
> This is a blockquote
> Great for important text
```

## Tips & Tricks

### Tip 1: Auto-Numbering Lists
```
Type "1. " and press space to auto-start numbered list
Type "- " and press space to auto-start bullet list
```

### Tip 2: Quick Headers
```
Use keyboard shortcuts for fastest header creation:
Ctrl+Alt+2 → Heading 2
Ctrl+Alt+3 → Heading 3
```

### Tip 3: Table Organization
```
Create table for:
- Meeting agendas
- Project tracking
- Comparison data
- Team assignments
- Budget planning
```

### Tip 4: Link Management
```
Always use meaningful link text
Instead of: https://example.com
Use: Click here for more information
```

### Tip 5: Document Structure
```
Best Practice Order:
1. Title (Main heading concept)
2. Introduction paragraph
3. Formatted sections (H2/H3)
4. Bullet lists for key points
5. Tables for data
6. Conclusion

Creates professional, readable documents
```

### Tip 6: Undo is Your Friend
```
Pressed wrong button? No problem!
- Ctrl+Z undoes changes
- Ctrl+Shift+Z redoes changes
- Use liberally while learning!
```

## Troubleshooting

### Text Not Formatting
```
Problem: Button clicks don't format text
Solution: Make sure text is selected before clicking button
```

### Table Toolbar Not Showing
```
Problem: Table tools don't appear
Solution: Click inside the table to activate it
```

### Link Not Working
```
Problem: Link doesn't open when clicked
Solution 1: Make sure URL includes http:// or https://
Solution 2: Hold Ctrl while clicking to open in edit mode
```

### Content Not Saving
```
Problem: Changes disappear
Solution: Editor auto-saves to database
If still missing: Check your internet connection
```
